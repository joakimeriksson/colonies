Who ran what, on whose machine

Fed by a script that runs colonies usage ... --json every five seconds and drops the files next to this page. No server changes involved. Pick a viewer to see what each identity is allowed to see.

Balance per member

colonies usage balance --from 30d

Net is provided minus consumed. Self-use is shown but not netted. Hours are reserved capacity times wall time.
